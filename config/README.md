# Config templates

Copied into `data/` on first start. `scripts/apply-config.sh` then keeps ports, MOTD, max players, view distance, and `online-mode` in sync with `.env`.

| File | Destination |
| --- | --- |
| `server.properties` | `data/server.properties` |
| `geyser.yml` | `data/plugins/Geyser-Spigot/config.yml` (first run) |
| `floodgate.yml` | `data/plugins/floodgate/config.yml` (first run) |

`data/plugins/floodgate/key.pem` is generated by Floodgate. Never commit it. Geyser on the same Paper process picks it up automatically.
